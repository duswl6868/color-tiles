냥냥 컬러타일 — 첫 번째 해변 마을 시안 모바일 PNG 팩

기준 화면: 세로 1080 x 1920
에셋 22개 + 조립 미리보기 PNG 1개

cats/: 고양이 8종, 각 256 x 256, RGBA 투명 PNG
ui/: 타이틀, 소리/재시작/빈 버튼, 빈 점수 패널, 물고기/시계 아이콘, 진행 막대 바탕/채움 (9개)
board/: 투명 프레임, 크림/샌드 칸 배경, 조립된 10열 x 14행 빈 보드 (4개)
background/: 해변 마을 1080 x 1920 배경 (1개)

사용 방법
- 배경 > 빈 보드 > 고양이 타일 > 상단 UI 순서로 배치하세요.
- board_10x14.png 내부 격자: 시작 (80,80), 칸 84 x 84 px, 10열 x 14행입니다.
- 반응형 보드는 frame.png와 cell_cream.png / cell_sand.png로 구성할 수 있습니다.
- 고양이는 동일한 캔버스와 중앙 기준점을 사용합니다.
- panel_blank.png는 점수와 시간 표시 영역에 공통 사용합니다. 숫자는 이미지에 포함하지 않았습니다.
- progress_fill.png는 폭 자체를 찌그러뜨리지 말고 클리핑/마스크로 표시량을 조절하세요.
- 버튼 이미지는 기본 상태입니다. 눌림/비활성 상태와 효과음은 포함하지 않습니다.
- layout_1080x1920.json은 배치 예시이며, 실제 단말의 상하 안전 영역을 반영하세요.
- manifest.json에서 각 파일의 실제 크기와 알파 여부를 확인할 수 있습니다.

제작 범위
첫 번째 시안을 참조하여 내장 이미지 생성 도구로 분리 가능한 요소를 복원한 뒤 개별 PNG로 잘라 정리했습니다. 원본 레이어 추출이 아니므로 타이틀 줄바꿈, 캐릭터의 표정/광택, 세부 형태가 시안과 완전히 같지는 않습니다. 생성된 투명 가장자리에 미세한 잔여 픽셀이 있을 수 있어, 실제 앱의 표시 크기와 배경에서도 최종 확인하세요. 바탕 그림 속 풍경과 장식 고양이는 배경에 포함되어 있습니다.
