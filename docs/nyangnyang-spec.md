## 1. 콘셉트
해변 마을을 배경으로 한 **말랑한 고양이 타일** 퍼즐이다. 규칙은 원작과 같고, 판 크기와 연출만 모바일 세로 화면에 맞춰 바꿨다.

## 2. 규칙 (원작과 동일, 제한 시간만 90초)
1. **빈칸**을 누르면, 그 칸에서 **위·아래·왼쪽·오른쪽으로 가장 가까운 고양이** 4마리(판 끝이면 그보다 적다)를 본다.
2. 그중 **같은 색이 2마리 이상**이면 그 색 고양이들이 모두 사라진다. 여러 색이 동시에 짝이 되면 모두 사라진다.
3. 사라진 고양이 1마리 = **1점**.
4. 아무것도 사라지지 않으면 **헛손질: −10초**.
5. **고양이 위를 누르면 아무 일도 없다.** 감점도 없다.
6. **90초**가 끝나거나 **모두 지우면** 게임이 끝난다. 더 지울 수 없게 막혀도 끝내지 않는다.

## 3. 수치
| 항목 | 값 | 코드 | 원작 |
|---|---|---|---|
| 격자 | **10열 × 14행 = 140칸** | `C=10, R=14` | 23×15 |
| 고양이 | **80마리** = 10색 × 8마리 (채움률 57%) | `TILES=80`, `PER` 자동 계산 | 200 = 10×20 (58%) |
| 시간 | **90초** | `TIME=90` | 120초 |
| 헛손질 | −10초 | `PENALTY=10` | 같음 |
| 점수 | 1마리 1점, 최대 80 | — | 1개 1점, 최대 200 |

- **색 수 자동 결정**: `assets/cats/`에 실제로 있는 고양이 이미지만 쓴다. 색당 마리 수는 `floor(80 / 색 수 / 2) × 2`로 정한다(색마다 짝수). 지금은 10색이라 8마리씩이다.
- **판 깔기**: 140칸을 섞은 뒤 앞 80칸에 색을 차례로 넣는다. 원작(색 풀을 섞어 행 우선으로 깔기)과 **같은 균등 분포**이며, §10에서 검증했다.

## 8. 기록
- **퍼펙트 시간**: 걸린 시간(헛손질 감점 포함)을 0.1초 단위로 **내림**한다. 원작 `timeUpTime`과 같은 계산이다.
- **최고 기록** (원작에 없는 추가 기능, `cattiles-record`)
  - 점수가 높을수록 좋은 기록이다. 점수가 같으면 퍼펙트 시간이 짧을수록 좋은 기록이다.
  - 표시는 "👑 전부 쏙! 49.9초" 또는 "👑 62마리".
- 저장은 `localStorage`를 쓰고 `try/catch`로 감싼다. iOS `file://`처럼 저장이 막혀도 게임은 그대로 동작한다.

## 10. 로직 동일성 검증
원작 원본(O), 리팩토링본(R), 우리 게임(U)을 같은 입력에서 비교했다.
- **O**: 난독화를 푼 원작 함수 본문을 **수정 없이** 실행했다. 판정 `_0x2f46fd`, 시간 `_0x3bf121`, 종료 `_0x5b75f8`, 셔플 `_0x534da7`, 결과 화면 시간 문자열이 대상이다. 화면 객체(CreateJS)만 가짜로 대체했다.
- **U**: `index.html`의 `scan()` 본문을 그대로 실행했다.
- 스크립트: `docs/original/verify_logic.js` (원작 코드를 포함하므로 git에서 제외)

**검증기 자체 검증(뮤테이션 테스트)**: 일부러 로직을 틀리게 바꾼 버전으로 다시 돌려 검증기가 실제로 차이를 잡는지 확인했다.
- 우리 짝 조건을 "2 이상"에서 "3 이상"으로 바꾸면 → 5개 항목 FAIL
- 원작의 위·아래 비교 한 줄을 지우면 → 7개 항목 FAIL

**검증 범위 밖**: 시간 흐름 방식(§9 의도된 차이), 연출, 사운드, 레이아웃은 동일성 비교 대상이 아니다. 실제 클릭으로 퍼펙트까지 간 E2E는 배포본에서 따로 확인했다. 15.7초 퍼펙트, 기록 저장·표시, 낮은 점수로 덮어쓰지 않음을 확인했다.

## 11. 기술 구성
- **게임**: `index.html` 파일 하나(HTML/CSS/JS)와 `assets/` PNG. 빌드 없이 GitHub Pages로 배포한다.
- **Expo 앱** (`app/`, SDK 58): 화면 하나짜리 WebView로 배포 주소를 연다. 게임을 고치면 앱을 다시 빌드하지 않아도 반영된다.
- **조정용 상수** (`index.html` 맨 위): `C`, `R`, `TILES`, `TIME`, `PENALTY`, `ALL_CATS`
