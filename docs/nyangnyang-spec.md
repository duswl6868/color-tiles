# 기획서 — 냥냥 컬러타일

- 플레이: https://duswl6868.github.io/color-tiles/
- 레포: `duswl6868/color-tiles` (게임 `index.html` + `assets/`, Expo 앱 `app/`)
- 고전 웹 퍼즐 gamesaien「Color Tiles」에서 영감을 받았다.
- 이 문서의 수치는 모두 `index.html` 코드를 기준으로 한다. 줄 번호는 작성 시점 기준이다.

---

## 1. 콘셉트
해변 마을을 배경으로 한 **말랑한 고양이 타일** 퍼즐이다. 모바일 세로 화면에서 한 손으로 짧게(90초) 즐기도록 만들었다.

## 2. 규칙
1. **빈칸**을 누르면, 그 칸에서 **위·아래·왼쪽·오른쪽으로 가장 가까운 고양이** 4마리(판 끝이면 그보다 적다)를 본다.
2. 그중 **같은 색이 2마리 이상**이면 그 색 고양이들이 모두 사라진다. 여러 색이 동시에 짝이 되면 모두 사라진다.
3. 사라진 고양이 1마리 = **1점**.
4. 아무것도 사라지지 않으면 **헛손질: −10초**.
5. **고양이 위를 누르면 아무 일도 없다.** 감점도 없다.
6. **90초**가 끝나거나 **모두 지우면** 게임이 끝난다. 더 지울 수 없게 막혀도 끝내지 않는다.

## 3. 수치
| 항목 | 값 | 코드 | 이유 |
|---|---|---|---|
| 격자 | **10열 × 14행 = 140칸** | `C=10, R=14` | 폰에서 한 칸 ≈ 30pt. 더 키우면 오터치가 늘어난다 |
| 고양이 | **80마리** = 10색 × 8마리 (채움률 57%) | `TILES=80`, `PER` 자동 계산 | 초반엔 어디를 눌러도 터지고 후반엔 멀리 봐야 하는 밀도 |
| 시간 | **90초** | `TIME=90` | 퍼펙트에 ≈40수 → 막판에 쫓기는 긴장 |
| 헛손질 | −10초 | `PENALTY=10` | 마구 누르기 방지 |
| 점수 | 1마리 1점, 최대 80 | — | — |

- **색 수 자동 결정**: `assets/cats/`에 실제로 있는 고양이 이미지만 쓴다. 색당 마리 수는 `floor(80 / 색 수 / 2) × 2`로 정한다(색마다 짝수). 지금은 10색이라 8마리씩이다.
- **판 깔기**: 140칸을 섞은 뒤 앞 80칸에 색을 차례로 넣는다(균등 분포). 색마다 짝수라 **모든 판은 순서만 맞으면 전부 지울 수 있다**(시뮬레이션: 무작위 1회 17%, 순서를 바꿔 최대 300회 시도하면 100%).

## 5. 화면 구성
### 5.1 무대
- **1080 × 1920** 좌표계 하나를 화면에 맞게 통째로 키우거나 줄인다(`layout()`). 폰, PC, 태블릿에서 배치가 같다.
- 무대 바깥(PC 양옆, 긴 폰의 위아래)은 같은 배경을 흐리게(blur 28px) 깔아 채운다.

### 5.3 시작·결과 카드 (화면 기준 크기, 최대 폭 360px)
- **시작**: 타이틀 로고(카드 위쪽 테두리 가운데에 걸침), 고양이 10종(5×2), 규칙 요약, 최고 기록, **[시작!]**
  - 규칙 요약(3줄, 가운데 정렬): "빈칸을 톡! 누르면 / 위·아래·양옆 고양이 중 / **같은 색끼리** 쏙 사라져요" + "짝이 없으면 **−10초**" (한 줄 16자 이내 — 폰에서 줄바꿈 없음)
  - 최고 기록은 규칙 문구 아래 **금색 배지**(`.record`)로 분리해 보여 준다
- **대기**: [시작!]을 누르면 판이 깔리고 시간은 90초에 멈춰 있다(안내 문구 없음). 판을 먼저 훑어볼 수 있다
  - **첫 터치**(화면 어디든, 보드 밖 포함)에 시간이 흐르기 시작하고 시작음이 난다. **판 위를 눌렀다면 그 터치도 바로 판정한다**(짝이 있으면 지우고, 없으면 −10초). 판 밖이면 시작만 한다
  - 대기 중 소리·다시하기 버튼은 원래 기능만 하고 게임을 시작하지 않는다
- **결과**: 제목, 점수, 부가 문구, 최고 기록 배지(갱신 시 "✨ 최고 기록! ✨"), **[한 판 더!]**
  - 퍼펙트: "53.2초 만에 전부 지웠어요"
  - 시간 종료는 남은 수에 따라 "아깝다"를 강조한다 (모든 판은 순서만 맞으면 깰 수 있다 — §3)

    | 남은 고양이 | 제목 | 문구 |
    |---|---|---|
    | 1~2마리 | 아깝다! 😿 | 딱 N마리만 더 지우면 됐는데! |
    | 3~5마리 | 거의 다 왔어요! | N마리 남았어요 · 순서를 바꾸면 깰 수 있어요 |
    | 6마리 이상 | 시간 끝! | 남은 고양이 N마리 |
  - 결과 카드는 종료 후 **0.6초** 뒤에 뜬다.

## 6. 연출
| 상황 | 연출 | 시간 |
|---|---|---|
| 빈칸 터치 | 분홍 발바닥 자국 | 0.6초 |
| 제거 | 누른 칸부터 고양이까지 **지나간 칸이 그 고양이 색으로 반짝임** | 0.45초 |
| 제거 (합체) | 짝이 된 고양이들이 줄을 따라 **누른 칸으로 빨려 들어옴** (작아지며 이동) | 0.15초 |
| 제거 (합체) | 누른 칸에서 한 마리로 **뭉쳤다가 펑** + 지운 색 입자가 사방으로 튐(6 + 마리 수×2개) + "냥!" 등 말풍선(3마리 이상이면 "+N!") + "뾱" 소리 | 0.28초 / 0.38초 / 0.8초 |
| 헛손질 | "−10초"(빨강) + 보드 좌우 흔들림 | 0.8초 / 0.3초 |
| 남은 20초 이하 | 게이지가 빨갛게 바뀌고 깜빡임 | 0.6초 주기 |
| 배치 | 고양이마다 −3°~+3° 랜덤 기울기 | — |

## 7. 사운드 (Web Audio 합성, 음원 파일 없음)
| 상황 | 소리 |
|---|---|
| 시작 | 660 → 990Hz 2음 |
| 제거 | 마리 수만큼 "뾱"(삼각파, 0.06초 간격). 한 번에 많이 지울수록 시작음이 높아짐 |
| 헛손질 | 200 → 110Hz 낮은 "뿌우"(사각파) |
| 남은 20초부터 | 1초마다 1300Hz 짧은 째깍 |
| 퍼펙트 | 도·미·솔·도 올라가는 4음 |
| 시간 종료 | 솔·미·도·솔 내려가는 4음 |

- 소리 버튼으로 켜고 끈다(`cattiles-sound` 저장).
- iOS·Safari는 사용자가 터치하기 전에는 소리를 막아서, **[시작!]**을 누를 때 소리를 켠다(`Sound.unlock()`).

## 8. 기록
- **퍼펙트 시간**: 첫 터치부터 전부 지울 때까지 걸린 시간(헛손질 감점 포함)을 0.1초 단위로 **내림**한다.
- **최고 기록** (`cattiles-record`)
  - 점수가 높을수록 좋은 기록이다. 점수가 같으면 퍼펙트 시간이 짧을수록 좋은 기록이다.
  - 표시는 금색 배지 "👑 최고 기록 전부 쏙! 49.9초" 또는 "👑 최고 기록 62마리".
- 저장은 `localStorage`를 쓰고 `try/catch`로 감싼다. iOS `file://`처럼 저장이 막혀도 게임은 그대로 동작한다.

## 9. 설계 결정
| 항목 | 결정 | 이유 |
|---|---|---|
| 시간 흐름 | 프레임 기준, 한 프레임 최대 0.1초 → 탭을 내리면 사실상 멈춤 | 모바일에서 앱 전환 시 억울함 방지 |
| 시작 | [시작!] 후 판을 보여 주고 **첫 터치부터** 시간이 흐름 (첫 터치도 바로 판정) | 판을 훑어볼 여유, 한 번의 터치로 바로 플레이 |
| 막혔을 때 | 게임을 끝내지 않음 | 규칙 단순성. 아깝게 놓친 판은 시간 종료 문구로 보상 |
| 기믹 | 없음 (조커·피버·시간 보너스 고양이는 시험 후 제거) | 조커가 색 짝수를 깨서 "항상 몇 마리 남는" 판을 만들었음 (전부 제거 14% → 0.6%) |
| 남은 시간 | 게이지 + 숫자(초) | 가독성 |
| 최고 기록 | 점수 → 같으면 퍼펙트 시간 | 퍼펙트 이후에도 시간 단축이라는 목표가 남음 |

## 10. 테스트
- **판정 로직**: 무작위 판(여러 크기, 1~10색, 빈 판~꽉 찬 판)에서 `scan()` 결과·점수·헛손질 판정을 독립 구현과 대조 (12만 건 수준)
- **E2E (실제 마우스 클릭, 배포본·로컬)**
  - 퍼펙트까지 플레이 → 결과 문구·걸린 시간·기록 저장/표시, 낮은 점수로 덮어쓰지 않음
  - 시작 흐름 → 첫 터치 전 시간 정지, 첫 터치 판정(제거/−10초), 대기 중 버튼 동작
  - 시간 종료 문구 3단계 경계값(1·2·3·5·6·40마리)
  - 합체 연출: 점수는 터치 즉시, 지운 수만큼 날아감, 합체까지 ≈160ms·연출 끝까지 ≈550ms, 끝난 뒤 남는 요소 없음

## 11. 기술 구성
- **게임**: `index.html` 파일 하나(HTML/CSS/JS)와 `assets/` PNG. 빌드 없이 GitHub Pages로 배포한다.
- **Expo 앱** (`app/`, SDK 58): 화면 하나짜리 WebView로 배포 주소를 연다. 게임을 고치면 앱을 다시 빌드하지 않아도 반영된다.
- **조정용 상수** (`index.html` 맨 위): `C`, `R`, `TILES`, `TIME`, `PENALTY`, `ALL_CATS`
